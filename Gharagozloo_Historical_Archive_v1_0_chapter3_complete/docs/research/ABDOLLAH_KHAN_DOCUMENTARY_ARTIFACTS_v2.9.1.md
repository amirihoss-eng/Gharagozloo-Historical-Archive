# Majmooe Asaar — Abdollah Khan Decrees, Appointments & Documentary Artifacts v2.9.1

## Scope

Migration 0044 catalogs the reproduced handwritten documentary appendix concerning **Haji Abdollah Khan Gharagozloo (P0004)**.

The source volume labels this section as decrees, orders, and appointments concerning Abdollah Khan. The surviving reproductions are handwritten Qajar administrative documents with seals and marginal endorsements.

## Evidence layer

This checkpoint distinguishes three layers already present in the archive:

1. **Abdollah Khan's authored reports/travelogues** — primary authorial evidence.
2. **Enayatollah Majidi's notes/introduction** — secondary editorial evidence.
3. **Reproduced decrees/orders/appointments** — primary documentary evidence.

The third category is the subject of Migration 0044.

## Conservative cataloging rule

The document scans are difficult handwritten Persian administrative texts.

Therefore this migration does **not** guess:
- exact document dates;
- issuing authorities;
- rank/title wording;
- offices;
- jurisdictions;
- salaries;
- seals;
- marginal endorsements.

Instead each page is cataloged as an artifact with:

- source = Majmooe Asaar;
- page-level file reference;
- artifact type = official document scan;
- transcription status = `transcription_pending`;
- confidence = provisional;
- direct association with P0004.

## Current artifact boundaries

Nine page-level artifact records are created for PDF pages **43–51**.

These are page-level records, not an assertion that there are exactly nine separate historical documents. One research question explicitly asks whether adjacent pages belong to the same multi-page document.

## Event policy

A documentary decree should normally **strengthen an existing event**, not create a second event for the same appointment or title grant.

The archive should preserve:
- one historical event;
- multiple evidence paths.

## Paleography policy

Do not use low-confidence OCR to manufacture exact text from these pages.

Preferred next steps:
1. inspect higher-resolution page images;
2. manual Persian paleographic transcription;
3. identify seal / issuing office;
4. compare wording with known Qajar farman templates;
5. match document to existing event/title/role record;
6. then add precise claims and citations in a later migration.
